# Le Baobab Doré

Site vitrine statique d'un restaurant fictif à Dakar (projet scolaire). HTML5, CSS3 et JavaScript Vanilla.

## Ouvrir en local

Double-cliquer sur `index.html`. Une connexion Internet est nécessaire pour les photos et les polices.

## Publier avec GitHub Pages

1. Créer un dépôt public sur GitHub.
2. Envoyer **le contenu** du dossier `restaurant/` à la racine du dépôt (`index.html` doit être à la racine).
3. Aller dans **Settings > Pages**, choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Après une à deux minutes, le site est disponible à `https://VOTRE-UTILISATEUR.github.io/NOM-DU-DEPOT/`.

## Activer le formulaire (FormSubmit)

1. Dans `contact.html`, remplacer `VOTRE_EMAIL@example.com` par votre adresse e-mail.
2. Publier le site, puis envoyer un premier message depuis la page en ligne.
3. Cliquer sur le lien d'activation reçu par e-mail.

Tant que l'adresse n'est pas remplacée, le formulaire valide les champs mais n'envoie rien (mode démonstration).
L'envoi ne fonctionne pas depuis un fichier ouvert en local. L'adresse placée dans le code est visible publiquement.

## Organisation

- `*.html` : les 8 pages
- `assets/css/style.css` : mise en forme et responsive
- `assets/js/main.js` : menu, filtres, animations, validation du formulaire
- `assets/images/` : logo et image de remplacement
